# Nexvia Technology Internship Projects

This repository contains the two projects I completed during my internship at Nexvia Technology.

Both projects helped me learn how to use machine learning and deep learning in practical applications.

## Projects

### 1. AI-Assisted Medical Imaging and Diagnosis System

This project uses deep learning models to analyze medical images. It includes chest X-ray classification and CT scan lung segmentation.

**Main Features:**
- Chest X-ray classification using DenseNet121
- CT scan segmentation using 3D U-Net
- Grad-CAM heatmaps
- FastAPI backend and React frontend
- DICOM integration using Orthanc
- Docker and DVC support

[View Project 1](./AIML-02/)

### 2. Large-Scale Personalized Recommendation Engine

This project recommends movies to users based on their ratings and interests. It uses neural networks, similarity search, and a ranking model to generate recommendations.

**Main Features:**
- Two-Tower Neural Network
- User and movie embeddings
- FAISS for movie retrieval
- Neural network ranking model
- Recommendation evaluation
- Redis caching
- Spark, Airflow, and Triton integration

[View Project 2](./AIML-03/)
